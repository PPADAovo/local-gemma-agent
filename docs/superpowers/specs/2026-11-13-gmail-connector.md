# Gmail 연결 화면 요구사항

## 목표

로컬 앱의 Gmail 항목을 Codex 연결 앱의 실제 상태와 기능에 연결하고, 처음 사용하는 사람도 한 번의 OAuth 안내로 연결을 마칠 수 있는 상세 화면을 제공한다.

## 요구사항

- Gmail부터 지원하고 기존 Codex app-server와 연결 정보를 재사용한다. Google API 키나 비밀번호를 로컬 앱에 새로 입력하게 하지 않는다.
- 연결 상태와 제공 기능은 app-server의 실제 플러그인·도구 정보로 표시한다. 계정 정보는 사용자가 Gmail 상세 화면을 열었을 때 읽기 전용 `gmail.get_profile` 결과가 제공하는 값만 표시한다.
- 연결되지 않은 경우 공급자가 제공한 HTTPS 연결 URL을 열어 안내하고, 사용자가 돌아온 뒤 실제 상태를 새로 조회한다. OAuth가 완료되지 않았는데 연결된 것처럼 표시하지 않는다.
- 연결되지 않은 Gmail도 앱 목록에서 찾을 수 있어야 한다. Codex 앱 목록에서 숨겨져 있으면 실제 Gmail 플러그인 목록을 사용해 연결 항목을 제공한다.
- 앱 이름·설명·게시자·도구·계정 같은 정보는 실제 공급자 메타데이터가 있을 때만 표시한다. 확인되지 않은 계정명·권한을 꾸며내지 않는다.
- 추천 요청은 채팅 입력란에 작성만 한다. 메일 조회·작성·발송은 해당 채팅 요청과 기존 승인 흐름을 따른다.
- 공급자가 실제로 지원하지 않는 연결 해제·삭제 동작은 버튼으로 제공하지 않는다. 오류와 미지원 상태는 화면에 명시한다.
- 화면 문구는 한국어로 작성한다.

## 구현 근거

- 현재 Codex app-server는 Gmail 플러그인을 설치·활성화 상태로 보고하며 `gmail.get_profile` 등 Gmail 도구를 제공한다.
- 기존 연결 확인 코드는 라벨 개수만 반환한다. `gmail.list_labels`는 실제 app-server 도구 목록에 등록돼 있으며, 계정 표시는 상세 화면에서 `gmail.get_profile`을 사용한다.
- 현재 플러그인 ID가 있는 요청은 탭 종류와 무관하게 로컬 서비스 처리기로 먼저 전달되어 Codex 플러그인 상세·설치 요청에 도달하지 않는다.
- 계정·메일 내용은 구현 준비 단계에서 조회하지 않았다.
