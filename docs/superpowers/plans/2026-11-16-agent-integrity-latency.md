# 에이전트 지연·응답 무결성 개선 계획

**Goal:** 반복 연결 준비와 잘린 응답, 도구 결과 연결 오류를 수정하고 원본·사본을 검증한다.
**Architecture:** 기존 실행·승인 경로를 보존한다. 설정 캐시는 파일 및 환경 변경 시 무효화하고, 출력 한도 재생성은 실행 전에만 수행한다.
**Tech Stack:** Node.js 24, Windows PowerShell, .NET Framework WPF.
**Spec:** 2026-11-16 사용자 요청: 전체 호환성·무결성 검토, 속도 및 도구 연동·답변 단절 수정, 원본·사본 모두 반영.

## Constraints / Review Focus
- 계정·대화·개인 설정을 복사하거나 변경하지 않는다.
- 진행 중인 다른 소스 변경을 덮어쓰지 않는다.
- 잘린 도구 지시를 실행하지 않는다. 재생성에 실패하면 명시적으로 오류를 반환한다.
- 정상 응답은 추가 모델 호출 없이 반환한다.
- 도구 결과는 호출 ID와 연결하고 실행 순서를 유지한다.
- 설정 변경·키 삭제·환경 변경은 캐시에서 즉시 반영한다.

## Tasks
- [x] cloud-brain.mjs: 같은 설정의 중복 읽기 테스트 → 실패 확인 → 파일 메타데이터·환경 지문 캐시, 반환값 격리 → 테스트.
- [x] conversation.mjs: 일반 및 도구 응답의 length 종료 테스트 → 실패 확인 → 제한된 출력 한도 재시도, 잘린 결과 실행 방지 → 테스트.
- [x] simple-loop.mjs: 연속 도구 결과 ID·순서 테스트 → 실패 확인 → 결과 ID 보존 → 테스트.
- [x] 전체 JS 테스트, PS 구문, 의존 파일, 별도 디렉터리 빌드 확인.
- [x] 바탕화면 최신 실행 파일 세트를 백업 후 문서 사본에 동기화. 사용자 데이터 제외. 두 경로의 해시와 테스트 재확인.
