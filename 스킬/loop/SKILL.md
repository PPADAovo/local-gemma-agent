# 반복 실행

간격 반복은 schedule_add 의 `every <분>` 으로 처리한다. 이 대화 안에서 계속 도는 것이 아니라, 정해진 간격마다 새 작업으로 실행된다.

순서:
1. 반복할 요청과 간격(분)을 확인한다. 간격이 없으면 묻는다. 5분보다 짧으면 5분으로 하자고 제안한다.
2. 언제 멈출지 확인한다(예: "빌드가 통과하면", "오늘 18시까지"). 멈추는 조건을 요청 문장 안에 넣는다.
3. schedule_add text="<요청>. <멈추는 조건>이 되면 schedule_remove로 '<이름>' 예약을 지우고 결과를 note에 남겨라." target="every <분>" path="<이름>"
4. schedule_list 로 등록을 확인하고, 멈추려면 "<이름> 반복 꺼 줘"라고 말하면 된다고 알린다.

끄기: schedule_remove text=<이름>
앱이 꺼져 있는 동안에는 반복되지 않는다.
