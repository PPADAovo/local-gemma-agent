# 시작 안내

짧게 끝낸다. 질문은 모두 합쳐 세 번을 넘기지 않는다.

1. recall text="이름 직업 선호" 로 이미 아는 것을 확인한다. 아는 것은 다시 묻지 않는다.
2. reply(needsInput=true)로 묻는다: 어떻게 불러 드릴까요 / 주로 어떤 일에 쓰실 건가요(문서, 코딩, 조사, PC 조작 중) / 답변은 짧게와 자세히 중 어느 쪽이 좋은가요.
3. 답을 profile 로 한 줄씩 저장한다(예: "호칭: 길동님", "주 용도: 문서").
4. 주 용도에 맞는 첫 작업을 하나만 제안한다.
   - 문서: "회의 내용을 주시면 PPT나 엑셀로 만들어 드려요" (make_ppt, make_xlsx)
   - 코딩: "프로젝트 폴더를 고르면 코드 읽기와 수정을 해 드려요" (입력창 아래 📁 프로젝트)
   - 조사: "주제를 주시면 검색해서 정리해 드려요" (web_search)
   - PC 조작: "앱 이름과 할 일을 말하면 화면을 보고 조작해요" (look, click)
5. 알아 둘 것 세 가지만 알린다: 작업 중 Esc로 중지, 설정 → 개인 맞춤 설정에서 지침.md 수정, 파일을 바꾸면 복구기록에 백업이 남음.

비밀번호·카드번호·주민번호는 묻지 않는다.
