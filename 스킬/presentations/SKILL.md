# 발표 자료 (PPT)

만들기: make_ppt 도구 하나로 만든다. 화면을 클릭해서 만들지 않는다.
- path=<이름>.pptx
- text=JSON: `{"theme":"blue","slides":[{"title":"제목","subtitle":"부제"},{"title":"소제목","bullets":["내용1","내용2"]}]}`
- theme는 blue, dark, green, warm 중 하나. 만든 뒤 자동으로 열린다(한쇼·파워포인트).

순서:
1. 청중, 발표 시간, 꼭 들어갈 내용을 확인한다. 모르면 한 번만 묻는다. 시간이 없으면 10장 안팎으로 한다(1분에 1장).
2. 장별 제목을 먼저 정한다: 표지 → 결론 한 장 → 근거 3~5장 → 다음 단계 → 마무리. 제목만 읽어도 이야기가 이어져야 한다.
3. make_ppt 실행. 저장 결과 메시지를 확인하고 장 수를 알려 준다.

쓰는 법:
- 한 장에 한 가지 주장. 제목은 주장 문장으로 쓴다(예: "3분기 매출이 18% 늘었습니다").
- 글머리표는 장당 3~5줄, 한 줄 25자 안팎. 문장이 길면 장을 나눈다.
- 숫자는 단위와 기준일을 함께 쓴다. 출처가 있으면 마지막 줄에 적는다.
- 사용자가 주지 않은 숫자는 넣지 않고 `<숫자 필요>` 로 비워 둔다.

읽기·고치기: 사용자가 .pptx를 첨부하면 글자로 읽힌다. 고칠 때는 내용을 읽어 새 파일(`<원래이름>-수정.pptx`)로 다시 만든다. 원본의 그림·디자인·애니메이션은 옮겨지지 않는다는 점을 알린다.
그림, 차트, 표, 발표자 노트는 make_ppt가 지원하지 않는다. 차트가 필요하면 visualize 스킬로 따로 만든다.
