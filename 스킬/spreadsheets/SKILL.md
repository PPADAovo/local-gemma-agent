# 표 (엑셀 .xlsx, CSV)

만들기: make_xlsx 도구 하나로 만든다.
- path=<이름>.xlsx
- text=JSON: `{"sheets":[{"name":"시트1","rows":[["항목","금액"],["광고",3000000],["합계","=SUM(B2:B2)"]]}]}`
- 숫자는 따옴표 없이 숫자로, `=` 로 시작하면 수식. 15자리가 넘는 긴 숫자(계좌번호, 원주율 등)와 0으로 시작하는 번호(전화번호)는 따옴표를 붙여 글자로 넣는다.
- 만든 뒤 자동으로 열린다.

순서:
1. 어떤 열이 필요한지, 합계·평균 같은 계산이 필요한지 확인한다.
2. 첫 줄은 열 이름(단위 포함: "금액(원)"), 한 줄에 한 건씩 넣는다.
3. 합계·평균·비율은 값을 직접 적지 말고 수식으로 넣는다(`=SUM(B2:B10)`, `=AVERAGE(...)`, `=B2/B$11`). 수식의 범위가 실제 데이터 줄과 맞는지 줄 번호를 세어 확인한다.
4. 직접 계산한 값을 넣어야 하면 calc 도구로 계산한다. 암산하지 않는다.
5. make_xlsx 결과의 줄 수가 넣은 줄 수와 같은지 확인한다.

읽기·분석:
- .xlsx는 사용자가 첨부하면 표로 읽힌다. .csv는 read로 읽는다.
- 줄이 많으면(200줄 이상) run으로 집계한다. 예: run text=`Import-Csv '<파일.csv>' | Group-Object 분류 | Select-Object Name,Count`
- 분석 결과는 숫자와 함께 한두 문장으로 말하고, 표가 필요하면 새 시트나 새 파일로 만든다.

고치기: 원본을 바꾸지 않고 새 이름(`<원래이름>-수정.xlsx`)으로 만든다. 원본의 서식·차트·매크로는 옮겨지지 않는다는 점을 알린다.
차트, 셀 색·테두리, 피벗 테이블, 열려 있는 엑셀 창 직접 조작은 지원하지 않는다. 차트는 visualize 스킬로 만든다.
