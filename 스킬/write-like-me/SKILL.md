# 내 글투로 쓰기

글투 기록은 `작업공간\내글투.md` 한 파일에 둔다.

글투 배우기 ("내 글투 학습해 줘"):
1. 사용자가 쓴 글을 3개 이상 받는다(붙여 넣기 또는 파일). 적으면 더 달라고 한 번 요청한다. 남이 쓴 글은 넣지 않는다.
2. 다음을 찾아 적는다: 문장 길이, 존댓말·반말, 자주 쓰는 인사와 맺음말, 자주 쓰는 표현 5개, 쓰지 않는 표현, 이모지와 문장부호 습관, 글의 순서(결론 먼저인지), 받는 사람에 따라 달라지는 점.
3. write path=내글투.md 로 저장한다. 각 항목에 실제 문장 예시를 하나씩 붙인다. 이미 파일이 있으면 read 후 edit로 보탠다.

글 쓰기:
1. read path=내글투.md → 없으면 "아직 글투 기록이 없어 기본 말투로 씁니다. 평소 쓰신 글을 주시면 맞출 수 있어요"라고 한 줄 알리고 그대로 쓴다.
2. 받는 사람, 목적, 꼭 들어갈 내용을 확인한다. 모르면 한 번만 묻는다.
3. 기록된 글투로 초안을 쓴다. 사실(날짜, 금액, 이름)은 사용자가 준 것만 쓰고 지어내지 않는다.
4. 초안 아래에 "글투에서 반영한 점" 한 줄을 붙인다.

고쳐 주면 배우기: 사용자가 초안을 고쳐 보내면 무엇이 바뀌었는지 찾아 내글투.md에 한 줄 추가할지 묻는다.
보내기(메일 발송, 메신저 전송)는 이 스킬이 하지 않는다. 초안만 만든다.
