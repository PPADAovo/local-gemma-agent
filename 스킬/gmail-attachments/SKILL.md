# 첨부 파일을 Gmail로 보내기

순서:
1. 받는 사람, 제목, 본문, 첨부 파일을 사용자 요청에서 확인한다.
2. plugin_search로 Gmail의 발송 도구와 입력 형식을 확인한다. "나한테 보내"나 "내 이메일로"면 받는 사람을 to="me"로 그대로 쓴다(계정 주소를 따로 조회하지 않는다).
   발송은 gmail.send_attached_email 한 번으로 끝난다. Gmail 웹 화면을 열거나(local.gmail.open) 작성 화면을 클릭할 필요가 없다.
3. 요청한 수신자 주소를 프로필이나 요청에서 확인할 수 없으면 reply(needsInput=true)로 묻는다. 주소를 추측하거나 기억에서 비슷한 이름을 골라 넣지 않는다.
4. 스크린샷 첨부 요청은 look을 한 번 호출해 캡처하고, 반환된 capturePath를 files 배열에 그대로 사용한다. 동영상이 명시적으로 요청되지 않았다면 record_screen을 사용하지 않는다.
5. 다른 새 파일을 요청하면 먼저 대화에서 사용자가 가리킨 자료를 확인하고 write로 저장한다. “그 지침”의 대상이 불분명하면 어느 지침인지 묻는다. 새 파일은 files 배열에 저장한 상대 경로만 명시한다. 기존 채팅 첨부만 보낼 때는 files를 생략한다. gmail.send_attached_email을 한 번 실행한다.
6. 결과의 메시지 ID를 확인한 뒤 보고한다: 받는 사람 / 제목 / 첨부 파일 이름 / 메시지 ID.

규칙:
- 제목과 본문은 사용자가 준 문장을 그대로 쓴다. 직접 지어 쓴 본문은 보내기 전에 보여 주고 확인받는다.
- 사용자가 제공한 첨부파일이나 이번 작업에서 저장한 파일이 있는지 확인한다.
- 한 번 발송에 성공하면 같은 요청으로 캡처하거나 다시 발송하지 않는다.
- 실패하면 같은 메일을 다시 보내기 전에 오류를 읽는다. 보내졌는지 불분명하면 다시 보내지 말고 사용자에게 보낸편지함 확인을 요청한다.
- Gmail 연결이 안 되어 있으면 설정의 플러그인에서 Gmail을 연결해 달라고 알린다. 비밀번호는 묻지 않는다.
