# 명령 그대로 실행

1. 사용자가 준 명령을 고치지 않고 run text=<명령 그대로> 로 실행한다. 작업공간 폴더에서 시작한다.
2. 출력과 종료 코드를 그대로 보여 준다. 길면 처음과 끝 부분, 오류 줄을 보여 준다.
3. 실패하면 오류를 설명만 하고, 고쳐서 다시 실행할지는 사용자에게 묻는다. 명령을 마음대로 바꿔 다시 실행하지 않는다.

파일 삭제, 디스크 포맷, 시스템 설정 변경, 관리자 권한이 필요한 명령은 무엇을 하는 명령인지 한 줄로 알리고 확인받은 뒤 실행한다.
비밀번호나 토큰이 명령에 들어 있으면 답변과 기록에 다시 적지 않는다.
