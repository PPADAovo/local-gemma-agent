# 웹 화면 확인

순서:
1. 종류 확인: 프로젝트 폴더에 package.json이 있고 scripts에 dev나 start가 있으면 개발 서버 방식, 없으면 정적 HTML이다.
2. 열기:
   - 정적 HTML: browser_preview 로 그 .html 파일을 연다.
   - 개발 서버: run으로 프로젝트에 정의된 명령을 실행하고, 출력에 나온 주소를 browser_open 으로 연다. 주소를 추측하지 않는다.
3. 글자 확인: browser_read 로 제목과 방금 바꾼 요소의 글자가 실제로 있는지 본다.
4. 동작 확인: 버튼이나 입력이 바뀌었으면 browser_click / browser_type 한 뒤 browser_read 로 전후를 비교한다.
5. 모양 확인: 색·배치·크기처럼 글자로 알 수 없는 것은 look으로 브라우저 창을 본다.
6. 보고: 확인한 항목마다 "확인함 / 다름 / 미확인"으로 적는다.

규칙:
- 파일 저장, 페이지 표시, 상호작용 결과는 각각 실제로 본 시점에만 check 한다. 저장했다고 화면까지 확인한 것으로 치지 않는다.
- 화면이 예상과 다르면 캐시 탓으로 넘기지 말고 파일을 read로 다시 읽어 저장 내용을 확인한다.
- 페이지가 열리지 않으면 오류 문구를 그대로 적고, 같은 주소를 3번 넘게 다시 열지 않는다.
- 좁은 화면 확인을 요청받았는데 창 크기를 바꿀 수 없으면 "미확인"으로 적는다.
