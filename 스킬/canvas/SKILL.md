# 캔버스 (HTML 화면)

canvas 도구: path=이름(영문·한글, 확장자 없이), text=완전한 HTML. `작업공간\캔버스\<이름>.html` 로 저장되고 PC 브라우저에서 열린다. 같은 와이파이의 휴대폰에서 볼 주소도 돌려준다.

순서:
1. 무엇을 보여 줄지 확인한다. 데이터가 파일에 있으면 read로 읽는다. 없는 숫자는 지어내지 않는다.
2. HTML 한 파일에 CSS와 JavaScript를 모두 넣는다(다른 파일을 불러오지 않는다). 차트만 `https://cdn.jsdelivr.net/npm/chart.js@4.4.1` 를 쓸 수 있다.
3. canvas 실행 → 결과로 온 주소를 사용자에게 알린다.
4. 고쳐 달라고 하면 같은 path로 다시 canvas를 실행해 덮어쓴다(이전 내용은 복구기록에 백업된다).

만드는 법:
- 글꼴은 맑은 고딕, 본문 15px 이상, 휴대폰 폭에서도 가로로 넘치지 않게 한다(표는 `overflow-x:auto` 로 감싼다).
- 버튼·입력칸이 있으면 눌렀을 때 바로 결과가 보이게 하고, 새로 고침해도 남아야 하는 값만 localStorage에 넣는다.
- 숫자에는 단위와 자리수 구분(1,200만원)을 넣는다.

차트 위주면 visualize 스킬, 여러 쪽짜리 웹사이트면 sites 스킬을 쓴다.
