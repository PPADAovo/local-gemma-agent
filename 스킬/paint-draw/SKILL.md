# 그림판에 그리기

순서:
1. open_app text=그림판 → look으로 빈 캔버스와 도구 모음을 확인한다.
2. 쓸 도구(연필, 선, 타원)를 click으로 한 번 고른다.
3. drag로 그린다. 좌표는 가장 최근 look 이미지의 픽셀이다.
   - 직선: text="120,200;180,250"
   - 꺾은선 한 획: text="120,200;160,220;180,250"
   - 화면 비율 좌표: text="normalized:250,250;600,750" (각 축 0~1000)
   - 선·타원 도구는 시작점에서 끝점까지 한 번 drag, 자유곡선은 점을 여러 개 이어 한 번 drag.
4. 떨어져 있는 획은 drag를 따로 한 번씩 실행한다. 한 획은 점 2~64개.
5. 획을 그린 뒤 돌아온 화면에서 선이 실제로 그려졌는지 보고 다음 획으로 간다. 안 그려졌으면 같은 좌표를 반복하지 말고 도구 선택과 캔버스 위치를 다시 확인한다.

규칙:
- 그리기 전에 전체 구도를 plan에 획 단위로 적는다(예: 머리 원 → 몸통 선 → 팔 2획).
- 내용이 있는 기존 그림 위에는 사용자가 그 파일을 지정했을 때만 그린다.
- 저장은 요청받았을 때만 key text=ctrl+s 로 하고, 저장된 경로를 알린다.
