# 프런트엔드 디자인

원문(영어, 자세한 설명)은 같은 폴더의 원문.md에 있다. 필요할 때만 read로 연다.

1. 주제 정하기: 무엇을 위한 화면인지, 누가 보는지, 화면의 가장 중요한 할 일 하나를 한 줄씩 정한다. 요청에 없으면 직접 제안한다.
2. 설계 먼저 (코드 전에 짧게)
   - 색: 이름 붙인 hex 4~6개(바탕, 표면, 글자, 강조, 보조).
   - 글꼴: 1~2개. 두 개면 확실히 다르게. 본문 한 줄은 80자 이내.
   - 배치: 한 문장 설명 + 정렬 방향(왼쪽/가운데).
   - 이 주제만의 특징 하나: 첫 화면에서 가장 먼저 보일 것(제목, 이미지, 실제로 써 보는 부분 등).
3. 흔한 기본값 피하기 (요청이 원하면 따른다)
   - 크림색 바탕+세리프+테라코타 강조, 검정 바탕+형광 강조 하나, 모든 내용을 같은 둥근 카드에 그림자, 장식용 그라데이션.
   - 모든 제목 위의 대문자 꼬리표, 제목 속 한 단어만 색 바꾸기, 내용이 순서가 아닌데 01/02/03 번호 붙이기, 버튼마다 '→'.
   - 섹션마다 아래에서 올라오는 애니메이션. 움직임은 한 곳에만, 사용자 동작에 반응하는 것 위주로.
4. 만들기
   - 과감한 요소는 한 군데만, 나머지는 차분하게.
   - 기본 품질: 휴대폰 폭까지 반응형, 키보드 초점 보이기, 움직임 줄이기 설정 존중, 글자 대비 충분히.
   - CSS 선택자가 서로 덮어쓰지 않게(특히 섹션 사이 여백) 주의한다.
5. 글: 사용자가 이해하는 쉬운 말로. 버튼은 일어날 일을 그대로("변경 저장"). 오류 문구는 무엇이 잘못됐고 어떻게 고치는지. 빈 화면에는 다음에 할 일을 안내한다.
6. 확인: web-preview 순서로 browser_preview를 열어 데스크톱·좁은 화면을 보고, 위 3번의 기본값이 들어갔는지 스스로 점검한 뒤 고친다.
