# 카카오톡

순서:
1. open_app text=카톡 (이미 열려 있으면 focus text=카카오톡).
2. 나에게/나와의 채팅 열기: 현재 채팅 목록에 이름 옆 '나' 표시가 붙은 자기 채팅방이 이미 보이면 그 항목을 double_click하여 바로 연다. 자기 채팅방이 목록에 보이지 않을 때만 왼쪽 세로 도구막대의 맨 위 사람 모양 아이콘(친구 탭) → 제목 아래 첫 번째 내 프로필 행을 double_click → look. 더블클릭으로 자기 채팅방이 바로 열릴 수 있다. 메시지 말풍선과 하단 '메시지 입력' 칸이 보이면 이미 채팅방이다. 방 제목과 입력창을 확인하고 요청된 다음 단계로 간다(열기·확인만 요청했으면 완료). 이 화면에서 '나와의 채팅' 버튼을 찾거나 누르지 않는다. 메시지 목록 없이 프로필 카드만 열린 경우에만 실제 보이는 '나와의 채팅' 버튼을 click한다. 프로필에 한 번 클릭은 선택만 될 수 있으므로 double_click을 쓴다. 이 작업에는 ctrl+f 검색을 쓰지 않는다.
   다른 사람의 채팅방 열기: 채팅 목록에서 key text=ctrl+f → type text=<방 이름> → look으로 결과 목록에 그 방이 보이는지 확인 → 보일 때만 그 항목을 눌러 연다 → 열린 창 제목이 맞는지 확인한다.
   - 검색 결과가 비어 있으면 enter를 누르지 않는다(맨 위의 다른 방이 열린다). 검색어를 지우고 다른 경로를 찾는다.
3. 보내기: 입력칸 click → type text=<메시지> → key text=enter → 화면에 보낸 메시지가 보이는지 확인한다.
   파일(녹화·사진 등) 보내기: run text="Set-Clipboard -LiteralPath '<파일 전체 경로>'" → 채팅방 입력칸 click → key text=ctrl+v → 바로 look. 붙여넣으면 '파일 전송' 확인 창이 새로 뜰 수 있다. 그 창이 보이면 그 창의 '전송' 버튼을 click한다(채팅방을 다시 열거나 enter를 먼저 누르지 않는다) → look으로 채팅방 맨 아래에 방금 보낸 파일(파일 이름·동영상 칸)이 새로 생겼는지 확인한다. 화면에 새 파일이 보이지 않으면 보냈다고 말하지 않는다.

규칙:
- "나한테/나에게 보내"는 "나와의 채팅"으로 보내라는 뜻이다. 여는 길은 화면을 볼 때 함께 나오는 앱 메모를 따른다.
- 이미 보이는 목표 항목을 우선 사용한다. 채팅 목록의 이름 옆 동그란 '나' 배지는 자기 채팅방 표시이며, 상단 '친구' 필터나 ChatGPT 태그는 왼쪽 사람 모양 친구 탭과 다르다.
- 현재 탭은 목록 위 제목으로 확인한다. 제목이 '채팅'이면 아직 친구 탭이 아니다. 사람 아이콘이 화면에 존재한다는 사실만으로 친구 탭이 선택되었다고 판단하지 않는다. '채팅' 화면에서 자기 방을 못 찾았으면 왼쪽 좁은 세로 도구막대의 사람 아이콘을 먼저 click하고, look 결과의 목록 제목이 '친구'로 바뀐 뒤에만 맨 위 프로필을 찾는다. '채팅' 제목 옆 화살표, 검색 돋보기, 가로로 놓인 '친구' 필터는 이 아이콘이 아니다.
- 친구 탭 맨 위에서 '업데이트한 친구' 구역보다 위에 따로 표시되는 프로필이 내 프로필이다. 이름이 사용자의 호칭·오픈채팅 닉네임과 달라도 그것만으로 다른 사람이라고 판단하지 않는다. 그 행을 double_click한 다음 방 제목과 메시지 입력창을 확인한다. 맨 위로 한 번 스크롤한 뒤 같은 화면이면 더 스크롤하지 않는다.
- 자기 채팅방의 창 제목은 '나와의 채팅'이라는 고정 문구가 아니라 내 프로필의 계정 이름으로 표시된다. 바로 앞 화면의 내 프로필에서 연 창인지와 메시지 입력창으로 확인한다. 제목이 실명이라는 이유나 저장된 글의 내용이 개인적인 대화라는 이유로 타인의 방이라고 추측하지 않는다. OCR의 이름과 실제 창 제목이 한 글자 다르면 화면의 이름과 프로필을 연 경로를 함께 대조한다.
- 오픈채팅·단체방·다른 사람과의 방이 열렸으면 아무것도 입력하지 말고 esc로 닫는다. 요청한 방이 아닌 곳에는 절대 보내지 않는다.
- 받는 사람이 분명하지 않거나 같은 이름의 방이 여러 개면 보내기 전에 reply(needsInput=true)로 묻는다.
- 사용자가 준 문장을 그대로 보낸다. 직접 지어 쓴 내용은 먼저 보여 주고 확인받는다.
- 송금, 선물하기, 결제는 하지 않는다. 계정 로그인 비밀번호는 입력하지 않는다(앱 잠금은 아래 규칙대로).
- 화면에 잠금 화면(비밀번호 입력칸)이 보이면 비밀번호를 type으로 직접 치지 않는다. 저장된 비밀번호가 있으면 unlock_app text=kakaotalk 로 풀고, 없으면 user_action text="카카오톡 잠금을 풀어 주세요"로 요청한다. 푼 뒤에는 look으로 다시 확인하고 이어서 한다.
- 잠금 화면인지는 반드시 look으로 본 화면으로 판단한다. 보지 않고 잠겨 있다고 말하지 않는다.
- 클릭·입력은 click·type·key 도구로 한다. windows·look의 target 칸에 동작을 넣지 않는다.
- 보낸 뒤에는 어느 방에 무엇을 보냈는지 한 줄로 알린다.
