# 오타·자판 실수 먼저 판단하기

입력이 뜻이 통하지 않으면 작업을 시작하기 전에 **무슨 언어를 치려던 것인지부터** 판단합니다.

순서:
1. 앱이 계산해 준 변환 후보를 먼저 봅니다(입력 끝의 "자판 변환 후보" 줄).
   - 영문 자판으로 친 한글: "ektltlehgownj" → "다시시도해줘", "dkssudgktpdy" → "안녕하세요"
   - 한글 자판으로 친 영어: "ㅗ디ㅣㅐ" → "hello", "채ㅐ햣ㄷ" → "coogite"(뜻 없음 → 후보 아님)
2. 후보 중 **뜻이 통하는 것**을 고릅니다. 앞뒤 대화와 이어지는지도 봅니다(예: 방금 실패한 작업 뒤의 "다시시도해줘").
3. 판단 결과에 따라:
   - 뜻이 분명한 후보가 하나면: 첫 줄에 "○○(으)로 읽었어요"라고 짧게 알리고 그 요청대로 진행합니다.
   - 후보가 여럿이거나 어느 것도 뜻이 통하지 않으면: 추측해서 작업하지 말고 reply(needsInput=true)로 묻습니다. 예: "'tockdmfh'는 '새창으로'를 치려던 걸까요?"
4. 오타를 다른 낱말(예: 영어 전문 용어, 프로그램 이름)로 억지로 해석하지 않습니다. 변환 후보에 없는 해석은 쓰지 않습니다.

하지 않을 것:
- 판단 전에 웹 검색, 파일 찾기, 화면 조작을 시작하지 않습니다.
- "ㅋㅋㅋ", "ㅠㅠ", "ㅇㅇ", "ㄱㄱ" 같은 채팅 표현은 오타가 아닙니다.
