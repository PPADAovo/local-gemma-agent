# 문서 (Word .docx)

만들기:
1. 내용을 마크다운으로 쓴다. 쓸 수 있는 형식: `# 제목` `## 소제목` `### 작은 제목`, 문단, `- 글머리표`, `1. 번호 목록`, `| 표 |`, `**굵게**`.
2. write path=<이름>.md text=<전체 내용> 으로 저장한다.
3. run text=`node '<스킬폴더>\make-docx.mjs' '<이름>.md' '<이름>.docx'`
   → "저장: 경로 · 제목 n개, 문단 n개, 목록 n줄, 표 n개"가 나온다. 이 숫자가 쓴 내용과 맞는지 확인한다.
4. open_file path=<이름>.docx 로 열어 준다(한글·Word·한컴오피스에서 열린다).

읽기: 사용자가 .docx를 첨부하면 글자로 읽힌다. 파일 경로만 알면 대화창에 첨부해 달라고 한다.

고치기: 원본 .docx를 직접 바꾸지 않는다. 내용을 읽어 고친 마크다운을 만들고 새 이름(`<원래이름>-수정.docx`)으로 저장한다. 원본의 글꼴·머리글·그림은 옮겨지지 않는다는 점을 알린다.

쓰는 법:
- 첫 문단에 결론을 쓴다. 제목은 3단계까지만 쓴다.
- 비교하는 내용은 표로, 순서가 있는 내용은 번호 목록으로 쓴다.
- 날짜는 YYYY-MM-DD, 금액은 자리수 구분(1,200만원).
- 그림, 각주, 머리글·바닥글, 변경 내용 추적은 지원하지 않는다. 필요하면 못 한다고 말한다.

PDF가 필요하면 pdf 스킬, 발표 자료는 presentations 스킬, 표 계산은 spreadsheets 스킬을 쓴다.
