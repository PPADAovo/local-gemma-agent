# 템플릿 만들기

참고 문서 하나를 분석해 "같은 형식으로 새로 만드는 방법"을 스킬로 저장한다.

순서:
1. 참고 파일을 확인한다. 경로를 모르면 find_file text=기억나는 단어. 없으면 어떤 항목이 들어가는지 사용자에게 묻는다.
2. read로 읽는다(.pptx·.xlsx·.docx·.pdf는 첨부로 받으면 글자로 읽힌다). 제목, 목차 순서, 각 부분에 들어가는 내용의 종류, 표의 열 이름, 말투를 정리한다.
3. 매번 바뀌는 값(날짜, 이름, 숫자)과 그대로인 부분을 나눈다.
4. 이름을 정한다: `template-<영문이름>` (예: template-weekly-report).
5. write path=`<스킬폴더>\..\template-<이름>\SKILL.md` text=아래 형식.
6. read로 확인하고, "<이름> 템플릿으로 만들어 줘"라고 하면 된다고 알린다.

```
---
name: template-<이름>
description: <무슨 문서인지> 형식으로 새 문서를 만들 때 사용한다.
---
# <문서 이름> 템플릿

먼저 물을 것: <매번 바뀌는 값 목록>
구성: <부분 제목과 각 부분에 들어갈 내용, 순서대로>
표: <열 이름과 형식>
말투: <예: 개조식, 존댓말>
만드는 도구: <PPT는 make_ppt, 표는 make_xlsx, 글은 write(.md), 화면용은 canvas>
확인: 만든 파일을 다시 읽어 빠진 부분이 없는지 본다.
```

참고 문서 속 실제 이름·금액·연락처는 템플릿에 옮기지 않고 `<이름>`, `<금액>` 같은 자리 표시로 바꾼다.
