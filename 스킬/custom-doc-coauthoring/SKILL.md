# 문서 함께 쓰기

원문(영어, 자세한 설명)은 같은 폴더의 원문.md에 있다. 필요할 때만 read로 연다.

1. 맥락 모으기 (질문은 한 번에 3개 이내)
   - 이 문서를 누가 읽는지, 읽고 나서 무엇을 결정·행동해야 하는지, 꼭 들어갈 내용과 마감·분량을 묻는다.
   - 사용자가 자료를 붙여 넣거나 파일을 주면 read로 읽고 핵심만 요약해 맞는지 확인한다.
2. 구조 잡기
   - 제목 목록(목차)을 먼저 제안하고 확인받는다. 각 제목 아래에 한 줄로 무엇을 쓸지 적는다.
   - 빠진 정보가 있으면 [확인 필요: …]로 표시하고 계속 진행한다. 같은 질문을 반복하지 않는다.
3. 초안 쓰기
   - 한 번에 한두 절씩 write/edit로 파일에 쓴다. 쓴 뒤에는 read로 저장된 내용을 확인한다.
   - 결론·요청을 앞에 두고, 근거와 세부는 뒤에 둔다. 문장은 짧게, 전문용어는 처음 나올 때 풀어 쓴다.
   - 사용자가 고친 부분은 그 표현을 그대로 살린다.
4. 읽는 사람 입장에서 점검
   - 처음 읽는 사람이 물을 질문 3~5개를 적고, 문서만 읽고 답할 수 있는지 확인한다. 답이 없으면 보완한다.
   - 숫자·날짜·이름이 앞뒤로 일치하는지, [확인 필요] 표시가 남았는지 본다.
5. 마무리 보고: 파일 위치, 남은 [확인 필요] 항목, 사용자가 결정해야 할 점만 짧게 알린다.

하지 않는 것: 확인 없이 문서 전체를 갈아엎기, 사용자가 주지 않은 사실을 지어내기.
