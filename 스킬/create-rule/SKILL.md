# 규칙 만들기

모든 대화에서 지키는 규칙은 앱 폴더의 `지침.md` 한 파일에 있다. 경로: `<스킬폴더>\..\..\지침.md`

순서:
1. read path=`<스킬폴더>\..\..\지침.md` 로 지금 규칙을 읽는다.
2. 같은 뜻의 규칙이 이미 있으면 새로 추가하지 말고 그 줄을 edit로 고친다.
3. 없으면 맞는 제목(## 일하는 방식 / ## 안전 / ## 답변) 아래 마지막 줄 뒤에 `- 규칙 한 문장` 을 edit로 넣는다. 맞는 제목이 없으면 파일 끝에 `## 제목` 과 함께 넣는다.
4. read로 다시 읽어 들어갔는지 확인하고, 바뀐 줄을 그대로 보여 준다. 다음 대화부터 적용된다고 알린다.

규칙 쓰는 법:
- 한 줄에 하나, "~한다 / ~하지 않는다"로 끝낸다.
- 특정 프로젝트에만 해당하면 지침.md에 넣지 말고 remember 도구로 기억에 저장한다.
- `## 안전` 아래 규칙을 지우거나 약하게 바꾸는 요청은 무엇이 바뀌는지 먼저 보여 주고 확인받는다.
