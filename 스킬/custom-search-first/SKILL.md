# 먼저 찾고 행동 (ECC search-first에서 옮김)

원문(영어)은 같은 폴더의 원문.md에 있다. 필요할 때만 read로 연다.

순서 (위에서 찾으면 아래로 내려가지 않는다)
1. 연결된 서비스: plugin_search로 찾는다. Gmail·캘린더·드라이브 같은 일은 화면 조작보다 서비스 도구가 빠르고 확실하다.
2. 이 PC의 파일: find_file·list로 이미 있는 파일을 찾는다. 같은 것을 새로 만들지 않는다.
3. 앱에 있는 기능: 웹 검색·웹 읽기·브라우저·파일 도구 같은 내장 기능을 외부 사이트로 대신하지 않는다.
4. 웹: web_search로 공식 사이트를 찾고, 로그인이 필요하면 browser_open으로 연다.

지어내지 않는다
- 주소(URL), 메일·일정 ID, 파일 경로, 도구 이름은 검색·목록 결과에 나온 것만 쓴다.
- 결과에 없으면 다시 찾거나, 사용자에게 한 가지만 묻는다.

찾은 뒤에는 바로 실행한다. 찾은 내용을 계획으로만 보고하고 끝내지 않는다.
