# 업무 문서 템플릿

순서:
1. 아래 표에서 맞는 양식을 고른다. 애매하면 두 개를 보여 주고 고르게 한다.
2. "먼저 받을 것"이 없으면 한 번에 모아서 묻는다. 받지 못한 숫자는 지어내지 않고 `<숫자 필요>` 로 비워 둔다.
3. 구성 순서대로 내용을 쓰고, 표의 "만드는 도구"로 저장한다(문서는 documents 스킬, 표는 spreadsheets 스킬, 화면은 canvas).
4. 만든 파일을 열어 주고, 비워 둔 칸 목록을 알려 준다.

| 양식 | 만드는 도구 | 구성 (순서대로) | 먼저 받을 것 |
|---|---|---|---|
| 사업 리뷰 | documents | 한 줄 결론 → 핵심 지표 표(목표·실적·차이) → 잘된 점 → 문제와 원인 → 다음 분기 조치(담당·기한) | 기간, 지표 실적 |
| 운영 리뷰 | documents | 요약 → 운영 지표 표(이번 달·지난달·변화) → 사고·지연 목록 → 원인 → 개선 조치 | 기간, 운영 지표 |
| 운영 캘린더 | spreadsheets | 열: 월·주차·일정·담당·준비물·상태. 분기별 시트 | 연도, 고정 일정 |
| 전략 메모 | documents | 결정할 것 한 문장 → 배경 → 선택지 2~3개(장점·단점·비용) → 추천과 이유 → 위험과 대비 → 필요한 결정 | 결정 사항, 선택지 |
| 팀 정렬 문서 | documents | 팀 목표 → 이번 분기 우선순위 3개 → 역할과 책임 표 → 일하는 방식(회의·보고 주기) → 합의 안 된 것 | 팀원, 목표 |
| 예산안 | spreadsheets | 열: 항목·분류·월별 금액 12칸·합계(수식)·비고. 아래에 분류별 소계와 총계(수식) | 기간, 항목과 금액 |
| 재무 3표 예측 | spreadsheets | 시트 3개: 손익(매출·원가·판관비·영업이익), 재무상태(자산·부채·자본), 현금흐름(영업·투자·재무). 가정은 별도 시트, 계산은 수식 | 기준 연도 실적, 성장 가정 |
| 투자 심의 메모 | documents | 투자 요약(금액·조건) → 사업과 시장 → 재무 현황 표 → 투자 논리 → 위험 요인 → 회수 방안 → 추천 의견 | 대상, 금액, 재무 수치 |
| 영업 파이프라인 | spreadsheets | 열: 고객·담당·단계·예상 금액·확률(%)·가중 금액(수식)·다음 행동·기한. 아래에 단계별 합계 | 거래 목록 |
| 시장 동향 보고서 | documents | 핵심 요약 3줄 → 시장 규모와 성장 → 주요 변화 3~5개(근거·출처) → 경쟁사 동향 표 → 우리에게 주는 의미 → 출처 목록 | 시장, 기간 (출처는 web_search로 찾고 주소를 적는다) |
| 프로젝트 착수 문서 | documents | 목적과 배경 → 범위(하는 것·안 하는 것) → 일정 표(단계·기한) → 역할 표 → 위험과 대비 → 성공 기준 | 프로젝트 이름, 기한, 참여자 |
| 프로젝트 추적표 | spreadsheets | 열: 작업·담당·상태·시작일·기한·진행률(%)·막힌 점. 아래에 상태별 개수(수식) | 작업 목록 |
| 지표 대시보드 | canvas | 위에 핵심 숫자 카드 3~4개 → 추이 선 차트 → 항목 비교 막대 차트 → 상세 표 | 지표 데이터 |
| 실험 분석 | documents | 가설 → 실험 설계(대상·기간·표본 수) → 결과 표(대조군·실험군·차이) → 해석(확실한 것과 불확실한 것) → 결정 | 실험 결과 숫자 |
| 시스템 설계 문서 | documents | 해결할 문제 → 요구 사항(해야 할 것·안 해도 되는 것) → 구성 요소와 흐름 → 데이터 구조 → 검토한 다른 방법 → 위험과 미정 사항 | 시스템 설명 |
| 디자인 검토 보고서 | documents | 검토 대상과 목표 → 잘된 점 → 문제 목록 표(위치·문제·심각도·개선안) → 우선순위 | 화면 캡처 또는 설명 |
| 법률 검토 메모 | documents | 질문 → 짧은 답 → 사실관계 → 관련 규정(사용자가 준 것만) → 검토 → 결론과 한계. 끝에 "법률 자문이 아니며 전문가 확인이 필요함"을 적는다 | 사실관계, 관련 조항 |

서식만 필요할 때:
- 레터헤드: documents로 만든다. 맨 위에 회사 이름(# 제목), 다음 줄에 주소·연락처, 날짜, 받는 사람, 본문, 맺음말과 서명 순서.
- 밝은 화면·어두운 화면: canvas로 만든다. 밝은 쪽은 배경 #FAFAFA·글자 #222, 어두운 쪽은 배경 #16181C·글자 #E8EAED.

법률 검토 메모의 관련 규정과 시장 보고서의 수치는 기억으로 쓰지 않는다. 사용자가 준 자료나 web_search로 찾은 출처가 있는 것만 쓴다.
