# 목표 설정

순서:
1. 목표를 한 문장으로, "끝났다"를 확인할 방법과 함께 정한다. 확인 방법이 없으면 묻는다(예: "테스트 전부 통과", "파일 3개 생성").
2. remember text="목표: <목표> / 완료 기준: <기준> / 시작: <오늘 날짜>" 로 저장한다.
3. plan 으로 3~8단계 할 일 목록을 만든다. 각 줄은 도구 결과로 확인할 수 있는 결과로 쓴다.
4. 단계마다 실제로 실행하고, 결과를 확인한 뒤에만 check 한다.
5. 이번 대화에서 다 못 끝내면 note text="목표 진행: 끝낸 단계 / 남은 단계 / 다음에 할 일" 을 남기고 사용자에게 남은 단계를 알린다.
6. 완료 기준을 실제로 확인했을 때만 "목표 달성"이라고 말하고 remember text="목표 완료: <목표>" 를 남긴다.

이어서 하기: 사용자가 "목표 계속"이라고 하면 recall text="목표" 로 찾아 남은 단계부터 진행한다.
막히면: 다른 방법을 세 가지까지 시도하고, 그래도 안 되면 무엇이 왜 안 되는지와 필요한 것을 알린다. 목표를 몰래 쉽게 바꾸지 않는다.
코딩 작업이면 3번에서 writing-plans 스킬로 계획 파일을 만들고 그 단계를 plan에 등록한다.
