# KakaoTalk 사용 메모 (기본)

앱과 함께 배포되는 기본 지식입니다. 형식은 `- 하려는 일 ⇒ 방법`이고, 직접 고치거나 줄을 더해도 됩니다.
이 PC에서 에이전트가 새로 배운 방법은 `기억/앱/KakaoTalk.md`에 따로 쌓이며, 같은 일이면 그쪽이 우선합니다.

- 나에게 보내기(나와의 채팅 열기) ⇒ "나에게"나 "나와의 채팅"은 방 이름이 아니라 검색해도 나오지 않음 → 왼쪽 맨 위 사람 모양 아이콘(친구 탭) → 목록을 맨 위로 스크롤 → 맨 위의 내 프로필을 double_click(더블클릭)으로 열기 → 메시지 목록과 입력칸이 보이면 자기 채팅방이 바로 열린 것. 프로필 카드만 보일 때에만 실제 보이는 "나와의 채팅" 버튼 클릭 → 새로 열린 채팅창 제목이 내 이름인지 확인
